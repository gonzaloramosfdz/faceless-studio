Faceless Studio

Short physics puzzles: predict what happens, then watch the simulation.

Faceless Studio is a small open-source tool that renders physics puzzle videos from code and uploads them to its owner's own YouTube channel. It is used by one person, the channel owner. It is not offered as a service to other users.

The Google sign-in for this app exists only so the tool can upload videos to that channel and read their public statistics.
